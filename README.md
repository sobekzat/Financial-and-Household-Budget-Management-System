# Financial and Household Budget Management System

##  Project Overview
This project is a complete database-driven system designed to manage
personal and household finances. It allows tracking income, expenses,
savings, bills, transactions, budgets, and financial accounts.

The system is implemented using **Oracle SQL & PL/SQL** and follows
database normalization principles, real-world business logic, and
advanced DBMS concepts.

---

##  Key Features
- Household-based budgeting
- Multi-account transaction tracking
- Income & expense categorization
- Savings goals with progress calculation
- Automatic balance updates using triggers
- Business rules enforced with triggers & exceptions
- Modular PL/SQL packages

---

##  Database Design
- 14 normalized entities
- Full ERD diagram
- Strong PK/FK relationships
- Referential integrity enforced

## Sample Business Logic
- Calculate monthly expenses per user
- Prevent expenses exceeding household budget
- Automatically update account balances
- Track savings goal progress
- Generate cash flow reports
